Midnight Brew: Asset List

Every sprite, sound and font in the game, grouped by what it's for. Midnight Brew draws all of its art in code when it starts, so there are no image files in the game itself: each picture below is the texture the game builds, exported as it appears on a 1080×1920 phone screen. Tap a picture to open the full-size PNG.

  • 105 sprites
  • 43 sounds, synthesized live
  • 2 system fonts
  • 0 image or audio files shipped
  • Exports total 4.7 MB

How to read the sizes. Design is the sprite's size in the game's own units (the play area is 360×640). Texture is the bitmap the game draws it into on a 1080×1920 phone (3.75× the design size; it scales with the screen). PNG is the size of the exported file.
